# survey9497 — 설문 집계기

`index.html` 하나로 동작하는 설문 집계기입니다. 엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 줍니다.

- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 안에서만 계산하며, 어디로도 보내거나 저장하지 않습니다(CSP로 네트워크 요청도 막음).

## 사용법
1. `index.html`을 브라우저로 엽니다(GitHub Pages로 내보내도 됩니다. 저장소 맨 위에 `.nojekyll`이 있습니다).
2. 엑셀에서 머리글 줄을 포함해 범위를 복사하고 입력란에 붙여넣습니다. 붙여넣으면 바로 집계하며, **집계** 버튼이나 Ctrl/⌘+Enter로 다시 집계할 수 있습니다.

## 집계 규칙
- 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 1~5 중 하나면 유효, 비었거나 공백만 있으면 빈 응답, 그 밖의 값은 제외입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다.
- 평균은 유효 응답 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 보여 주고, 유효 응답이 없으면 `-`입니다.

자세한 결정 사항은 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험
계산 로직은 `index.html`의 `<script id="tally-core">`에 화면과 떼어 두었고, `tests/tally.test.js`가 그 부분만 꺼내 시험합니다. Node 18 이상이면 설치할 것 없이 실행됩니다.

```bash
npm test
```
