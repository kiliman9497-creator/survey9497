# 설문 집계기 계획서

## 목표
엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 정적 페이지(`index.html` 하나).

## 제약
- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않는다. 시험도 Node 내장 `node:test`만 쓴다.
- 붙여넣은 데이터는 브라우저 밖으로 보내지 않고 저장하지 않는다.
  - 네트워크 요청 코드 없음. CSP(`default-src 'none'`, `connect-src` 미허용, `form-action 'none'`)로 한 번 더 막는다.
  - `localStorage`·`sessionStorage`·쿠키를 쓰지 않는다.
  - 입력란은 `<form>` 밖에 두고 `autocomplete="off"`, `spellcheck="false"`(브라우저의 클라우드 맞춤법 검사로 글이 나가는 것을 막음)로 둔다.
  - 데이터는 `textContent`로만 화면에 넣는다(HTML 주입 없음).
- 저장소 맨 위에 빈 `.nojekyll` 파일을 둔다(GitHub Pages가 Jekyll 처리 없이 그대로 내보내도록).

## 집계 규칙
| 항목 | 규칙 |
|---|---|
| 입력 | 탭으로 나뉜 칸, 줄바꿈(`\r\n`/`\n`/`\r`)으로 나뉜 줄. 첫 줄은 머리글. 엑셀식 큰따옴표 칸(`"a\tb"`, `""`)도 읽는다. |
| 집계 열 | 첫 열(응답번호)은 집계하지 않는다. 둘째 열부터 머리글의 각 칸이 문항이다. |
| 유효 | 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나 |
| 빈 응답 | 비었거나 공백만 있음 |
| 제외 | 그 밖의 값(`0`, `6`, `3.5`, `03`, `３`, `예` 등) |
| 모자란 칸 | 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 센다. |
| 평균 | 유효 응답 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지(예: 2.345 → 2.35). 유효가 0이면 `-`. 부동소수 오차를 피하려고 정수 연산으로 반올림한다. |

결과 표 열: 문항 / 유효 응답 / 평균 / 빈 응답 / 제외

### 규칙에 없는 경우의 처리(결정 사항)
- 길이 0인 줄(끝의 줄바꿈 등)은 응답 줄로 세지 않는다. 탭만 있는 줄은 응답 줄로 보고 모두 빈 응답으로 센다.
- 머리글보다 칸이 많은 줄의 남는 칸은 대응하는 문항이 없으므로 집계하지 않고, 그런 줄 수를 안내한다.
- 머리글 칸이 비어 있으면 문항 이름을 `(N열)`로 보여 준다.
- 머리글만 있고 응답 줄이 없으면 모든 문항을 0으로 보여 준다.

## 10×10 격자(추가)
결과 표 아래에 문항마다 10×10 바둑판을 하나씩 그린다. 1칸 = 그 문항 응답의 1%.
- 검은 돌 = 유효 응답, 흰 돌 = 제외, 빈 칸 = 빈 응답. 왼쪽 위부터 검은 돌 → 흰 돌 → 빈 칸 순서로 채운다.
- 칸 수는 최대 나머지 방식(`SurveyTally.toGridCells`)으로 나눠 합이 항상 100칸이다. 나머지가 같으면 유효 → 제외 → 빈 응답 순서로 먼저 받는다. 개수가 0인 항목은 칸을 받지 않는다.
- 아주 작은 비율(예: 0.1%)은 0칸이 될 수 있으므로 판 아래에 실제 개수와 평균을 함께 적는다.
- 응답 줄이 없으면 빈 판과 "응답 없음"을 보여 준다.

## 구조
- `index.html`
  - `<script id="tally-core">`: 화면과 무관한 순수 계산 로직(`SurveyTally.parseTsv`, `classifyCell`, `formatAverage`, `tally`). DOM을 건드리지 않는다.
  - 화면 스크립트: 입력을 받아 `SurveyTally.tally`를 부르고 표를 그린다.
- `tests/tally.test.js`: `index.html`에서 `tally-core` 스크립트를 꺼내 `node:vm`으로 실행하고 시험한다. 페이지가 외부 자원을 부르지 않는지, 저장·전송 API를 쓰지 않는지도 검사한다.
- `package.json`: `npm test` → `node --test tests/*.test.js` (의존성 없음)
